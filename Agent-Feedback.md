# Agent Feedback

Things agents noticed that every future agent might need to know. Newest first.
Agents add entries here; only a person moves an entry into `AGENTS.md`. See `AGENTS.md` section 7.

Entry format:

```markdown
## YYYY-MM-DD: <one-line title>

- **Seen in:** <branch or PR, files involved>
- **What happened:** <what you saw, specifically>
- **Why it matters:** <what goes wrong if the next agent doesn't know this>
- **Suggested rule:** <the line you would add to AGENTS.md>
- **Status:** open
```

Status is `open`, `added to AGENTS.md` or `rejected`, and only a person changes it.
